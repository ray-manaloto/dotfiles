# Agent workflow

How an idea becomes a merged pull request when Claude Code and Codex share the work. These files
are installed at user scope (`~/.config/agents/workflow/`) and apply in every repository; a
repository adds its own commands in a `## Workflow facts` section of its `AGENTS.md`.

* [The workflow](workflow.md) - the rules and the eight steps from idea to merged pull request.
* [Shipping a change](ship.md) - the commit gate, the verify gate, the pull request and the close-out.
* [Cross-review](cross-review.md) - the reviewer pane, the three review kinds and how findings are handled.
* [Skills the workflow uses](skills.md) - the six workflow skills and who may start each mattpocock skill.
