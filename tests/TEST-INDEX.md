# tests/ — Key Files Index

Split out of `tests/AGENTS.md` 2026-07-15. Not a style choice: agnix **AGM-003**
caps an `AGENTS.md` at 12,000 chars for **Windsurf** compatibility — a real,
vendor-documented limit (<https://docs.windsurf.com/windsurf/cascade/memories>:
"Limited to 12,000 characters per file"; AGENTS.md is "processed by the same
Rules engine"). AGM-003 measures the **file**, so moving reference
content out keeps `AGENTS.md` legal.

`tests/AGENTS.md` references this file by path rather than importing it: agnix
rejects `@import` in an `AGENTS.md` (Claude-only syntax in an agent-agnostic
file), and `claude_md_import_stub` requires every `CLAUDE.md` outside the
Claude-specific scope be solely an `AGENTS.md` import. So this is **on-demand
reference**, read when you need it —
appropriate for an index, and what the docs recommend for content that need not
sit in context every session.

Nothing was deleted. Every row is a pitfall that cost a real session to learn,
and `/doctor`'s trim heuristic says keep exactly this and cut what Claude can
derive instead.
