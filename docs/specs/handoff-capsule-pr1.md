## 1. Objective

A coordinator handoff is prose written at one moment and read once at launch (`coordinator_handoff.py:780-784`).
Anything that happens after that moment is invisible to the successor. Anything the prose misstates is believed.
The 04h audit measured both failures in one handoff:

- **Late events.** Run 671241e5 settled with **DO NOT SHIP** after the launch. Ledger run eb6af51c settled after the
  prose was written. `land -- 1662` exited rc=1.
- **A BLOCKED run read as "completed".** Settlement 9ba676b8 says `completed`, but its `output.md:1` says "Blocked
  before implementation".
- **A question the launcher dropped.** A question sat outside `## Queued questions`. The launcher reads only that
  section, so the brief said `_None._`.
- **A stale land list.** It still queued #1647, which the ship queue had already recorded as landed (rc 0).
- **A successor launched without `worktree.bgIsolation: none`.**

**Outcome.** A machine-collected **capsule** records:

- every source the handoff depends on, with a byte/record cursor and digest;
- every obligation derived from those sources (runs, inbox records, transcript requests and handbacks, heavy runs,
  owed lands, queued questions).

A read-only **check** then answers one question: *does this handoff dispose of every obligation through the capsule's
declared boundary, and has anything happened since?* Anything arriving after the boundary is reported as a pending
obligation, never silently dropped. A stale, incomplete, or unverifiable state fails (rc 1). It never passes.

**What this PR does not change:**

- **Routing.** No role bindings, epochs, or inbox routing changes; that is PR2.
- **Scheduling.** That is PR3.
- **The 30% threshold.**
- **The successor's transcript-review subagent** (requirement 13). The capsule supplements that judgement; it does not
  replace it.

Validity of a capsule grants **no shipping authority** (a3d6e816:200).


### 3d. The `## Obligations` handoff table (the disposition carrier; OC-1)

This follows the precedent that `session-state` output is "rendered in the claim words `handoff-check` verifies … so a
State section pasted from this output checks itself" (`session_state.py:14-16`):

```markdown
## Obligations

| id | disposition | evidence |
|---|---|---|
| run:9ba676b8ba6f47409aea60002d7027be | blocked | output sha256:3f1c…(>=8 hex) — re-dispatched e98b7c1d |
| land:1662 | pending | land-1662.log rc=1; retry per persistence-gate-retry |
```

The section ends at the next level-2 heading, the same rule as `coordinator_handoff.py:134-137`. Each row is
`id | disposition | evidence`. A non-`pending` row needs non-empty evidence. A `run:` row that is not `pending` must
cite `sha256:<prefix>` matching the run's **current** `output.md` digest.

### 3e. Collection rules (deterministic; every bound reports overflow)

1. **Repo.** Reuse `session_state.gather(repo_root, with_pr=…, since=…)` for branch, dirty paths, commits (full `%H`),
   and the PR lists. `head_sha = commits[0].sha`. `origin_main_sha` comes from a bounded `git rev-parse origin/main`
   (null on failure, with a warning).
   - `open_prs`/`merged_prs` of `None` → `available=false` with the error. Never an empty list.
   - `required_launch_settings` = `coordinator_handoff.CROSS_SESSION_SETTINGS`, imported, never re-typed.
2. **Handoff.** Record a cursor, the section count and body of `## Queued questions`, and `outside_section`.
   - `outside_section` holds every line outside that section's span that matches `(?i)\bqueued question` or
     `AskUserQuestion`.
   - Lines inside fenced code blocks are ignored (reuse `handoff_check._visible_lines`, whose fences are respected,
     `handoff_check.py:289`).
   - **Collect never edits the handoff.**
3. **Old transcript** (`coordinator_handoff.transcript_path`, `:432-437`). Record a cursor (size, line count, prefix
   sha256). Then walk records with `type == "user"` whose `message.content` is a string, classified by prefix:
   - `<local-command-caveat>`, `<command-name>`, `<command-message>`, `<local-command-stdout>` → ignored.
   - `"You ended the turn without"` → ignored as a harness reminder.
   - The first non-ignored record → ignored as `launch_brief`.
   - `<task-notification>` → not an obligation; see OC-3.
   - `"Another Claude session sent a message:"` → `cross_session`.
   - `"Here is a note offered by a side agent"` → `side_note`.
   - Anything else → `human`. An unrecognised prefix is never dropped.

   `user` records whose content is a list (tool results) are ignored. The prefix constants live in one module-level
   tuple.
4. **Subagent transcripts** (`<projects>/<slug>/<session>/subagents/*.jsonl`). Record a cursor per file. Every
   `tool_use` with `name == "SubagentHandback"` becomes a `handback` obligation.
   - `summary` = the first 200 chars of `input.message`, and `source_ref` = that file and line.
   - The payload digest is recorded in `summary`'s suffix (`sha256:<16 hex>`), taken from `input.message`, **never**
     from the last assistant text block.
5. **Inbox** (`<main>/.agent/plans/handoff-inbox/*.md`, `session_common.HANDOFF_INBOX`). Record a cursor per file.
   Each `## <stamp> — <title>` record (`handoff_inbox.record`, `:149-151`) becomes an `inbox_record` obligation when its
   stamp ≥ `since`.
   - Stamps parse with `datetime.fromisoformat`. Both `Z`-UTC and Chicago-offset forms exist on disk.
   - An unparsable stamp is **included**.
6. **Ship queue** (`<main>/.agent/plans/main-checkout-ship-queue.md`). Record a cursor. Extract `LANDED` claims with
   `handoff_check.extract_claims(text, source=<path>)` (`handoff_check.py:433-472`).
7. **sdlc runs.** For every worktree from `git worktree list --porcelain` of the main checkout (bounded `_GIT` timeout),
   glob `<wt>/.agent/sdlc-runs/*/` (`sdlc_team.SDLC_RUNS_DIR`). Include a run when `settlement.json` is absent, or when
   its `finished_at` ≥ `since`. Record cursors for `settlement.json` and `output.md`.
   - Set `outcome` from `classify_outcome` (rule 9).
   - Each included run → a `run:<run_id>` obligation.
8. **Heavy runs.** Use `coordinator_handoff.census(...)` (`:588-627`), then add `start_epoch_s` from `reap.Process.age_s`
   (`reap.py:96-103`). Status comes from the log's last `^rc=(\d+)$` line when the log is a regular file.
   - Each run → a `heavy:<pid>@<start_epoch_s>` obligation.
   - If `census` raises (no claude ancestor), record a warning plus an `overflow`-class gap. Never record an empty "none".
9. **`classify_outcome` (OC-4).** The settlement is process-terminal only. `COMPLETED` means codex rc 0 and spawn
   reconciliation consistent (`sdlc_team.py:1019-1037`); it carries no work verdict.

   | Input | Outcome |
   |---|---|
   | No settlement, pid alive | `RUNNING` |
   | No settlement, not alive | `ABANDONED` (mirror `read_status`, `:908-929`) |
   | `failed` | `FAILED` |
   | `timed_out` | `TIMED_OUT` |
   | `completed` | `output.md` lexicon (next list) |

   The lexicon reads only the **first paragraph** (text up to the first blank line):
   - case-sensitive `DO NOT SHIP` anywhere in it → `DO_NOT_SHIP`;
   - `^\W*Blocked\b` (case-insensitive) at its start → `BLOCKED`;
   - otherwise `UNCLASSIFIED`.

   The lexicon can only make an outcome stricter. **No input ever yields a positive outcome.** `outcome_evidence` is
   `output.md:1: <first line, <=200 chars>`.
10. **Lands.** For every PR in `pr_state.merged_since` without a `LANDED` claim in the ship queue, add a `land:<N>`
    obligation. If PR state is unavailable, add no land obligations and set `available=false`. Rule 2 of the check then
    fails.
11. **Bounds** (module constants):

    | Bound | Value |
    |---|---|
    | sources | ≤ 256 files |
    | sdlc runs | ≤ 64 |
    | obligations | ≤ 500 |
    | transcript records scanned per file | ≤ 20,000 lines |
    | digested bytes per file | ≤ 256 MiB |
    | `summary` | ≤ 200 chars |
    | `argv` | ≤ 512 chars |

    Exceeding any bound appends an `Overflow` entry. It never silently truncates.

### 3f. Check rules (each yields findings; any finding → rc 1)

1. **Re-observe every `SourceCursor`.**
   - Missing, shrunk, or `prefix_sha256` mismatch → `source_replaced`.
   - Grown → `source_advanced`, and the new records are classified by the same collect rules into `new_obligations`.
   - An sdlc run that gained `settlement.json` → `new_sdlc_settlement`, with outcome and evidence.
   - A changed `output.md` → `run_output_changed`.
2. **PR state.** `pr_state.available == false` → `pr_state_unavailable`. Either truncated flag → `pr_state_truncated`.
   `--no-pr` → `pr_state_unavailable` (fail closed; `handoff_check.py:12`: "A GitHub lookup that fails is a finding,
   never a pass").
3. `capsule.overflow` non-empty → `overflow`.
4. **Obligations table.** Parse it from the handoff.
   - A capsule obligation with no row → `obligation_undisposed`.
   - A row whose id is not in the capsule → `obligation_unknown`.
   - A non-pending row without evidence, or a `run:` row whose `sha256:` prefix does not match the current
     `output.md` → `disposition_evidence_mismatch`.
   - A `land:<N>` row that is `pending` while the ship queue carries a `LANDED` claim for N → `stale_land`, citing
     the queue line.
5. **Queued questions.**
   - `section_count > 1` → `duplicate_queued_section`.
   - Each `outside_section` line → `question_outside_queue`. This also fires when the section body is `_None._` while
     outside lines exist.
6. `--session <id>` (or the env id): read that session's harness job record via `session_common.job_record`
   (`session_common.py:77-84`). Then read **only** `respawnFlags`, `name`, `sessionId`, and `createdAt`.
   - Find the value following `--settings` and JSON-decode it.
   - Missing record, missing flag, or `worktree.bgIsolation != "none"` → `launch_settings_missing`.
   - Never read or print `intent` or any other key.
7. **Heavy runs.** Re-snapshot each pid and compare against the capsule.
   - The same pid with `|start_epoch_s − capsule.start_epoch_s| > 2` → `heavy_run_changed` (`PID_REUSED`).
   - A capsule `RUNNING` run that now has an `rc=` line → `heavy_run_changed`, with rc.
8. **Handoff citations.** Run `handoff_check.check_with_claims(repo_root, handoff_text, facts=…)`
   (`handoff_check.py:637-670`) and wrap each finding as `handoff_citation`.

## 4. Constraints and invariants

1. **Read-only except the capsule file.** `collect` writes exactly one file, under
   `<main>/.agent/state/handoff-capsule/`, atomically. `check` writes nothing.
   - Neither command edits the handoff, inbox, ship queue, `task_plan.md`, or any transcript.
   - Neither sends messages or launches anything.
2. **No routing, no scheduling, no authority.** A clean check grants no shipping or retirement authority. Do not call
   `retire`, `ship`, `land`, `SendMessage`, or `claude`.
3. **Unknown stays unknown.** Each of the following is a value or finding, never a pass:
   - failed `gh` → `available=false`, never `[]`;
   - process gone without `rc=` → `GONE_NO_RC`;
   - `completed` settlement → never a positive outcome;
   - unrecognised transcript prefix → `human` obligation;
   - unparsable inbox stamp → included.
4. **Generated models only.** No hand-written structs or enums for capsule types (`python/AGENTS.md` "Generated
   models"). All encode/decode goes through `codec` (ruff TID251).
5. **Zero-bash-logic.** All logic lives in Python. The mise task is a one-line thin caller.
6. **Bounded subprocesses.**
   - git: reuse `session_state._git` semantics, a 30 s timeout.
   - `gh`: `pr_facts.run_gh`, which has `GH_TIMEOUT`.
   - lsof/ps: the existing census path.
   - No unbounded waits and no polling.
7. **Secrets.**
   - Never read job-record keys other than the four named.
   - Never print environment values.
   - Excerpts are capped at 200 chars and come only from transcript/inbox text already on disk.
   - Do not add any file under `.agent/` to git.
8. **Preserve existing contracts.**
   - The 30% limit and +5% step (`coordinator_handoff.py:79-82`) stay as they are.
   - Census, retire, and `launch` rc semantics (`:817-832`) stay as they are.
   - Under OC-2, a capsule failure inside `launch` must **not** change launch's rc. It degrades to
     `capsule: UNAVAILABLE: <reason>` in the brief. A takeover must never wait on a quiet source (a3d6e816:29).
9. **Requirement 13 stands.** The brief still orders the transcript-review subagent; the capsule check is added before
   it, not instead of it.
10. **The public interfaces of `session_state`, `handoff_check`, `handoff_inbox`, `gate_result`, and `sdlc_team` stay
    unchanged.** Private helpers may be imported (`_visible_lines`), but not modified.
11. **No inline suppressions** (`no_lint_skip`).
12. **The lane runs no `mise run build` / `docker` / `ship` / `land`.** The architect runs every gate itself afterwards
    (`codex-sdlc-team.md` blind spot: `hook_guard` cannot see a codex lane's shell).
