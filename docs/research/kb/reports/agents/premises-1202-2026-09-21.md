## MISSING premises (not listed in the spec)

**M1 — BLOCKING. The hook budget is 10s, but `$` calls are free.** `HookBudget` (`claude-code.d.ts:4180-4206`) is a readonly literal type: `ms: 10_000`, `catchMs: 1_000`, `lingerMs: 5_000`. A hook past its budget "is absent (its `.catch` asked, else `next(e)` run on its behalf)" — i.e. **a budget overrun fails OPEN, the deny is dropped**. Critically, `:4176-4178` documents `await $.model.complete(ask) // a minute; next.budget.remainingMs unmoved`, and `:4192` says "its `next` replay and its `$` calls are free". So a `$.process.run` of up to 90s does **not** consume the 10s budget. The spec asks the implementer to "state your bound and why" — the real bound is python's own `_TIMEOUT_S = 20.0` per subprocess (`claude_doctor.py:136`) times two subprocesses, under the TS `timeoutMs: 90_000` ceiling. The cost is user-visible latency on the first denied call, not hook death. State that, and do **not** reach for a shorter TS timeout believing the budget requires it.

**M2 — BLOCKING. `$.fs` is on `$`, and the harness documents this exact guard — including the not-yet-existing-file case.** `claude-code.d.ts:2748-2799` gives `$.fs.stat(path, { resolve: true })` returning `realPath`, plus a worked `placed()` helper for "a Write may name a file not there yet". Its own warning is directly on point: *"an allow-list under it is the robust guard, a deny-list on spellings only best effort (a hard link or a case alias keeps its own)."* The spec's §4 exact-path rule is spelled entirely in string terms and normalises `..` only — it does **not** cover a symlink, hard link, or macOS case-insensitive alias pointing at the root `doctor.toml`. On a case-insensitive filesystem `<root>/DOCTOR.TOML` resolves to the same file and a string compare refuses it (fail-safe), while `<root>/link-to-elsewhere` named `doctor.toml` would be *permitted* by a string compare and write elsewhere (fail-open). Per `use-tool-builtins.md` this is a native feature the spec reinvents. Decide explicitly: string-normalise (cheap, best-effort, and say so) or `$.fs.stat`-resolve (one extra fs call, free against the budget per M1).
