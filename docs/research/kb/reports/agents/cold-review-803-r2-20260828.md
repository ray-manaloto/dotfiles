## Findings

**D1 — HIGH: the C1 refusal is silent, and the operator is told the image was
already removed.** `devcontainer_names.py:829-831`. Before the delta the same
input emitted the bare image id, so a resolver miss still produced a `docker rmi`
attempt that either worked or failed loudly. Now it is dropped with no
`logger.warning`, no stderr, no non-zero exit — and `mise.toml:1071-1074` prints
"already removed". The delta's own docstring names the producing state
(`:906-909`): *"the two docker calls behind the real default are separate
processes and can race"*. Probed: 28/28 container `.Image` values resolve today,
so it is not mis-firing now; the finding is that when it does, it is mute.

**D2 — MEDIUM: C2 makes the legacy container arm blind to UNTAGGED images — the
one thing the container path exists for.** `devcontainer_names.py:832`. For an
UNTRUSTED container an image with `refs.tags == ()` can never satisfy `any(...)`,
so it is refused. Concrete producing state: a pre-#677 stopped container whose
overlay tag was later moved to a rebuilt image, leaving the old image dangling
`<none>:<none>` while the stopped container still references it.

**D3 — MEDIUM: the untrusted branch is provably DEAD CODE, and its "control arm"
test does not exercise it.** MEASURED: mutating `:832` to bare `if trusted:`
leaves the suite **63 passed, rc=0**, including
`test_teardown_images_trusts_an_untrusted_containers_own_overlay`
(`tests/test_devcontainer_names.py:764-778`), whose docstring calls itself *"the
control arm for C2"*. It passes via `_orphaned_by_tag`, not via the branch it
names — right answer, wrong reason.

**D4 — MEDIUM: inverting the trust bit is invisible to the entire test suite.**
`devcontainer_names.py:717`. Mutating `==` → `!=` passes the WHOLE repo suite:
2481 passed, 2 failed, both unrelated and pre-existing. Root cause:
`_docker_container_images` has NO test. It is the sole producer of the value C2
depends on, parsed out of a subprocess.

**D5 — MEDIUM: the label key is a literal in the Go template, decoupled from
`WORKSPACE_LABEL`.** `devcontainer_names.py:705` hardcodes `"dotfiles.workspace"`
while the constant lives at `:149`. Verified on the real daemon: Go's `index` on
a missing key returns the EMPTY STRING, not an error, so the drift yields
`trusted=False` for every container silently.

**D6 — LOW: the "omitted vs present-but-empty" distinction is documented three
times and pinned nowhere.** `:947`. Mutating `is not None` → truthiness leaves
the suite **63 passed**. `mise.toml:1013` always passes the flag, so `""` is the
common production value.

**D7 — LOW:** the new `_IMAGE_INSPECT_FIELDS` guard has no test (`:757-761`).
**D8 — LOW:** stale `from_containers` docstring reference at `:597`.
