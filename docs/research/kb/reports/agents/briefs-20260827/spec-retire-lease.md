## 1. Objective

The repository writer lease (#753 and everything built on it: #759, #791, #796) is removed from the codebase, the CLI, the mise tasks, the hooks, the verification contracts, the tests and the instruction docs — so that no session, lane, or contract ever references, enforces, or tests it again. The single guarantee it provided — one writer per Git common dir — is covered by git's own refusal to check out one branch in two worktrees and by the orchestration rule of one live lane per checkout. Deletion over addition: nothing is kept "for later".
