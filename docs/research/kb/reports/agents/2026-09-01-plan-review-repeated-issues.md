## 3. What the plan is missing for repeated issues

1. **An enforcement-reach matrix.** Every proposed prevention needs four fields: interception point, failing fixture, passing control, and bypass surface. Phase 17 currently records behavior but does not distinguish “matcher absent” from “matcher present but invocation never reached it”; the repository itself warns that 125 measured commands bypassed the hook entirely (`.claude/rules/mise-tasks-only.md:55-85`).
2. **A same-branch, scoped #887 repair trigger.** The plan names the recurring drift but not the missing edge from a Renovate synchronization to named-tool shared/image lock updates; the only current refresh triggers are schedule/manual (`.github/workflows/refresh.yml:32-41`). The whole daily action is not that edge because it intentionally re-resolves floating pins (`.github/workflows/refresh.yml:12-18`).
3. **Accurate remediation for drift failures.** `_assert_no_version_drift` tells root/shared users to run the bare `mise run lock` (`tests/test_lock_coverage.py:121-131`), while the repository's safe task map requires a named host tool, `lock-shared` for shared pins, and `lock-image` for image locks (`AGENTS.md:20-32`). The gate fires, but its recovery instruction can create the next lock incident.
4. **A single typed completion protocol across launchers.** `codex-lane` has it; generic background tasks are **UNVERIFIED**. The plan should inventory each producer and name the file/API result its consumer accepts, because a notification hook cannot inspect a future inner result (`python/src/dotfiles_setup/hook_guard.py:788-805`).
5. **Removal of stale contradictory checks.** `orchestration.codex-only-lanes` says no grok route, while the eval still declares grok and asserts that configuration passes (`python/verification/suites.toml:1840-1851`; `python/src/dotfiles_setup/eval_cases.py:42-52`; `tests/test_eval_cases.py:83-97`). A green evaluator that blesses the motivating failure is worse than no evaluator.
6. **Exact hostile inputs for the remaining regression classes.** Seed the legacy Doppler file for F (`tests/test_docker.py:245-308` currently does not), replay an unavailable lane at the actual dispatcher for H, and require a structured control receipt for C. Each must demonstrate both rejection and a legitimate pass, per the repository's own standard (`.claude/rules/probes-need-a-control-arm.md:49-64,127-142`).
7. **A declared boundary for non-machine-enforceable claims.** C's intended token, D's prose diagnosis, and G's security characterization cannot be inferred reliably from shell text. Gate their consequential actions/evidence artifacts, and label the remaining semantic judgment as human review instead of claiming blanket prevention (`.claude/rules/probes-need-a-control-arm.md:127-133`).
