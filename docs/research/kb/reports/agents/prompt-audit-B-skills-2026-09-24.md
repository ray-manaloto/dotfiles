# Prompt Audit — Report B: repo-authored skills

**Scope (Step 0):** every repo-authored skill under `.claude/skills/` (SKILL.md plus any
supporting files) except the vendored `graphify/`, `context7-cli/`, `find-docs/` — 35 skill
directories, ~180 KB. `claude-doctor/` has no SKILL.md; its model-facing surface is the four
`additionalContext`/`deny` strings in `hooks/register.ts`, which were audited too.
**Target model:** Claude Opus 5.5 (thinking always on, effort default medium, follows
instructions closely and literally, and prescriptive skill scripts degrade it).
**Mode:** read-only. Nothing in the repo was edited. Every hunk below was generated by
`B-work/mkdiff.py` against the exact current file bytes. Each edit checks that its old text
occurs exactly once, and a planted bogus edit made the generator fail (rc=1), so the check
really does reject text that isn't there. All hunks also apply together without conflict,
and every `suites.toml` token bound in these skills survives the full set.
