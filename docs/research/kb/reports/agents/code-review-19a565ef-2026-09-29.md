**Finding**

- `tests/test_renovate_ignored_authors.py:28` — LOW — The docstring and TEST-INDEX say the scan catches EVERY commit identity, but the `_EMAIL` regex misses some spellings without failing:
  - an email without a literal `@`, such as `git config user.email "$EMAIL"` or `${{ ... }}`;
  - `git -c user.email=... commit`;
  - `git config --local user.email`;
  - identities passed as action inputs (`committer:`/`author:`), or the built-in identity `autofix-ci/action` commits under.

  If a future workflow commits onto a Renovate branch using one of these, the test stays green while Renovate freezes the PR again, which is the #1435 failure this gate exists to prevent. The `.yml`-only globs would also skip `*.yaml` files, though none exist today. Fix either by failing on any `user.email` or `_EMAIL` line whose value the regex can't parse, or by narrowing the claim in the docstring.
