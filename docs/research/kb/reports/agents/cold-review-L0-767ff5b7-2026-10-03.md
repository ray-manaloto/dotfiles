## Verified not-a-defect (control-armed)

- **command_audit RO-F1** (`command_audit.py:317-354`). Re-derived over the 60 most recent dotfiles
  transcripts instead of trusting the inherited "196 transcripts". `"toolUseResult":"Error: Exit code N\n` had 51 hits.
  The bare form without a newline had 0. The refusal prefixes are all distinct:
  `Error: PreToolUse` 37, `Error: This session` 18, `Error: The user` 5,
  `Error: Permission to` 4, `Error: No task` 4, `Error: This background` 2, `Error: Blocked` 1.
  Control: the catch-all `Error: [A-Z]` had 124 hits, all of them accounted for by these classes. The anchored
  regex discriminates.
- **session_orphans DE-F4** (`session_orphans.py:99-128`, `:224-245`). `harness_ids` never contains
  the root pid, so the `HARNESS`-parent shapes (`cat`, `date +%s`, `(<comm>)`) cannot be admitted
  directly under the session root. A Bash-tool `cat` that zsh exec'd under claude stays OTHER.
  The parent gating holds. Residual, not reported: a Bash-tool shell sampled in its pre-exec
  `(bash)` instant would be HARNESS for that one snapshot. On this host the Bash tool shell is zsh,
  so the shape is `(zsh)`, which does not match.
- **mise stdin forwarding**. `sleep 6 | mise run handoff-inbox -- append --lane ../bad` took 6 s, the
  same as the direct `uv run` control, so mise forwards stdin. The Bash tool's stdin is a character device
  that hits EOF at once (python `select` probe), so an agent that forgets `--message` gets the
  "empty body" refusal rather than a hang.
- **Moved symbols**. `git grep` at the ref finds no remaining consumer of
  `coordinator_handoff.COORDINATOR_NAME_RE`. Tests were repointed to `session_common`
  (`tests/test_coordinator_handoff.py:748,781`).
- **task_plan.md shape**. In the main checkout it is a regular file (not a symlink) and gitignored
  (`.gitignore:143`; control `README.md` rc=1), so the atomic replace neither breaks a link nor
  writes a tracked file on `main`.
