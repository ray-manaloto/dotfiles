## F1 — subshell and command substitution defeat the tokenizer (High)

`_SHELL_TOKEN_RE` (`workflow_claude_code.py:222`) is

```python
_SHELL_TOKEN_RE = re.compile(r"[^\s;&|)\"'`]+")
```

`)` is a terminator; **`(` and `$` are not**. So `$(hk` and `(hk` survive as one
token, and `_hooks_in_command` matches by exact equality
(`if word == "hk"`, :343). The replaced regex was `\bhk\b`, which matched across
a preceding `(` or `$(` because those are non-word characters.

The production arm, run on a `git archive` of the real repository with
`autofix.yml`'s own command rewritten and its install step deleted:


exists (`workflow_claude_code.py:14-16`: autofix.yml failed with
`[Errno 2] No such file or directory: 'claude'`).

No live workflow uses the shape today. `grep -rnE '(\$\(|\(|/)(hk|mise|dotfiles-setup) +(run|check|fix|lint|exec|c|f|r)\b'`
over `.github/`, `mise.toml`, `.config/mise/conf.d/`, `scripts/`, `.devcontainer/`
