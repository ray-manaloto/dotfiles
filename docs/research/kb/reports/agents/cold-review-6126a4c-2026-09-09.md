## Finding 1 in detail

`hooks.md:2346` and `:2542-2549` both state that `additionalContext` on
`SubagentStop` **keeps the subagent running** — "The conversation continues so
Claude can act on it… It keeps the conversation going through the same loop
protections as `decision: "block"`". The only documented difference is the
transcript label (`Stop hook feedback` vs a hook error).

The commit's stated motivation is that a lane which had already delivered
"re-explained itself three times". Since the continuation is unchanged, that
turn is still spent — the change alters how it reads, not whether it happens.
The diff's own evidence file concedes this: *"The three re-deliveries above are
consistent with that: the lane received three separate parent messages"*
(`docs/rules-evidence/agent-report-persistence.md:100-102`).

Two consequences the diff does not address:

- Every `Agent`-tool delegation in the repo now costs one extra model turn,
  unconditionally, because the registration is unscoped (matcher omitted).
- The forced turn becomes the subagent's **new final assistant message**. Where
  the parent consumes the delegate's last message as the tool result, a
  one-line "yes, I already delivered" can displace the substantive report. The
  stop text explicitly instructs "say so in one line and stop", which maximises
  that risk. *Marked partly UNVERIFIED*: the corpus states that the Agent tool
  returns the subagent's text output (`$CC/sub-agents.md:879`) but does not
  spell out last-message-wins, so the displacement is inferred, not documented.

If the goal is a reminder without a turn, `SubagentStart` alone already carries
the contract, and `hooks.md:2346` names the parent-side alternative explicitly:
a `PostToolUse` hook on the `Agent` tool.

correctly on py3.14 — not a defect. The gap is that `UnicodeDecodeError` is a
`ValueError`, so it escapes both arms (finding 11). Impact is bounded:
`$CC/hooks.md:870` puts a non-zero, non-2 `SubagentStart` exit on the
"shows stderr to user only" path, so it does not fail closed — but the module's
docstring says "fail open", and this arm prints a traceback instead.

(`cd /tmp`, `CLAUDE_PROJECT_DIR` set): rc=0 in 0.08 s warm, correct JSON. The
