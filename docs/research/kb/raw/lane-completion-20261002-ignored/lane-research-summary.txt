RESEARCH SWEEP COMPLETED: Lane Completion Detection Protocol
============================================================

RESEARCH QUESTION:
How should fan-out workflow watchers detect when a lane has finished?
The problem: KB2 finished work but showed "blocked" status, causing 7-day watcher loops.

KEY FINDING:
"Idle" (dimmed) is NOT a terminal state in Claude Code. Lanes need explicit completion signals.

SOLUTION PATTERN:
Lane is "done" when:
  1. Session state ∈ {done, failed, stopped} (terminal)
  2. Completion marker written (durable proof)
  3. State persisted ≥2 minutes

If lane idles >5 min without marker → watcher sends confirmation prompt
