# `mise bootstrap compose status` [​](https://mise.jdx.dev/cli/bootstrap/compose/status.html\#mise-bootstrap-compose-status)

- **Usage:**`mise bootstrap compose status [-J --json] [--missing]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show configured Docker Compose project state

## Flags [​](https://mise.jdx.dev/cli/bootstrap/compose/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 when any Compose project is not converged
- **`-h --help`** — Print help
