# Cookbook [​](https://mise.jdx.dev/mise-cookbook/\#cookbook)

These recipes combine tools, environment variables, and tasks for specific workflows. Start with the recipe closest to your project, then adapt its paths, versions, and application commands. Each recipe states the files or tools it expects to exist.

| Workflow | Recipe |
| --- | --- |
| Select Bazel from a project version file | [Bazel](https://mise.jdx.dev/mise-cookbook/bazel.html) |
| Configure and build a CMake project | [C++](https://mise.jdx.dev/mise-cookbook/cpp.html) |
| Install mise and share tools in containers | [Docker](https://mise.jdx.dev/mise-cookbook/docker.html) |
| Run npm scripts or select a package manager | [Node.js](https://mise.jdx.dev/mise-cookbook/nodejs.html) |
| Work with requirements files, uv projects, or inline scripts | [Python](https://mise.jdx.dev/mise-cookbook/python.html) |
| Run Rails and Bundler commands | [Ruby](https://mise.jdx.dev/mise-cookbook/ruby.html) |
| Initialize, validate, plan, and apply infrastructure changes | [Terraform and OpenTofu](https://mise.jdx.dev/mise-cookbook/terraform.html) |
| Highlight task scripts and configure embedded language servers | [Neovim](https://mise.jdx.dev/mise-cookbook/neovim.html) |
| Create your own project scaffold | [Presets](https://mise.jdx.dev/mise-cookbook/presets.html) |
| Customize prompts and inspect shell integration | [Shell tricks](https://mise.jdx.dev/mise-cookbook/shell-tricks.html) |

For the underlying behavior, see [task configuration](https://mise.jdx.dev/tasks/task-configuration.html), [environment variables](https://mise.jdx.dev/environments/), and [tool configuration](https://mise.jdx.dev/dev-tools/).
