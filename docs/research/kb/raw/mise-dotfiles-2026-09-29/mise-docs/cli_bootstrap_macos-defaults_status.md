# `mise bootstrap macos-defaults status` [​](https://mise.jdx.dev/cli/bootstrap/macos-defaults/status.html\#mise-bootstrap-macos-defaults-status)

- **Usage:**`mise bootstrap macos-defaults status [-J --json] [--missing]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show whether macOS defaults match `[bootstrap.macos.defaults]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/macos-defaults/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 if any configured defaults are not in their desired state
- **`-h --help`** — Print help

This is a compatibility spelling. Use [`mise bootstrap macos defaults status [-J --json] [--missing]`](https://mise.jdx.dev/cli/bootstrap/macos/defaults/status.html) in new scripts.
