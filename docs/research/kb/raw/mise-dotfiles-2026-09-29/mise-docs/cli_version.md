# `mise version` [​](https://mise.jdx.dev/cli/version.html\#mise-version)

- **Usage:**`mise version [-J --json]`
- **Aliases:**`v`
- **Effect:** read-only
- **Source code:** [`src/cli/version.rs`](https://github.com/jdx/mise/blob/main/src/cli/version.rs)

Display the version of mise

Displays the version, os, architecture, and the date of the build.

If the version is out of date, it will display a warning.

## Flags [​](https://mise.jdx.dev/cli/version.html\#flags)

- **`-J --json`** — Print the version information in JSON format
- **`-h --help`** — Print help

## Examples [​](https://mise.jdx.dev/cli/version.html\#examples)

```
mise version
mise --version
mise -v
mise -V
```
