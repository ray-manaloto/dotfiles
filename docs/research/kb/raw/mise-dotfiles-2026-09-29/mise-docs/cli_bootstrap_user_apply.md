# `mise bootstrap user apply` [​](https://mise.jdx.dev/cli/bootstrap/user/apply.html\#mise-bootstrap-user-apply)

- **Usage:**`mise bootstrap user apply [-n --dry-run] [-y --yes]`
- **Effect:** modifies state
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Apply current-user settings from `[bootstrap.user]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/user/apply.html\#flags)

- **`-n --dry-run`** — Print the commands that would run without running them
- **`-y --yes`** — Skip the confirmation prompt
- **`-h --help`** — Print help
