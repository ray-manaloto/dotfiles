# `mise bootstrap accounts status` [​](https://mise.jdx.dev/cli/bootstrap/accounts/status.html\#mise-bootstrap-accounts-status)

- **Usage:**`mise bootstrap accounts status [-J --json] [--missing]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show configured Linux user and group state

## Flags [​](https://mise.jdx.dev/cli/bootstrap/accounts/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 when any account is not converged
- **`-h --help`** — Print help
