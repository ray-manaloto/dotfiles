# `mise bootstrap linux systemd-units apply` [​](https://mise.jdx.dev/cli/bootstrap/linux/systemd-units/apply.html\#mise-bootstrap-linux-systemd-units-apply)

- **Usage:**`mise bootstrap linux systemd-units apply [-n --dry-run] [-y --yes]`
- **Effect:** modifies state
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Install and start systemd user services from `[bootstrap.linux.systemd.units]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/linux/systemd-units/apply.html\#flags)

- **`-n --dry-run`** — Print the commands that would run without running them
- **`-y --yes`** — Skip the confirmation prompt
- **`-h --help`** — Print help
