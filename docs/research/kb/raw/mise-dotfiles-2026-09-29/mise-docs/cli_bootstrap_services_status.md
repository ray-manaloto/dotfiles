# `mise bootstrap services status` [​](https://mise.jdx.dev/cli/bootstrap/services/status.html\#mise-bootstrap-services-status)

- **Usage:**`mise bootstrap services status [-J --json] [--missing]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show configured service state (system and user scope)

## Flags [​](https://mise.jdx.dev/cli/bootstrap/services/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 when any service is not converged
- **`-h --help`** — Print help
