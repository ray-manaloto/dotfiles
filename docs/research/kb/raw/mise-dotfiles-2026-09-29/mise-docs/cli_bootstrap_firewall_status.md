# `mise bootstrap firewall status` [​](https://mise.jdx.dev/cli/bootstrap/firewall/status.html\#mise-bootstrap-firewall-status)

- **Usage:**`mise bootstrap firewall status [-J --json] [--missing]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show configured Linux host firewall state

## Flags [​](https://mise.jdx.dev/cli/bootstrap/firewall/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 when the firewall is not converged
- **`-h --help`** — Print help
