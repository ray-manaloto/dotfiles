# `mise backends ls` [​](https://mise.jdx.dev/cli/backends/ls.html\#mise-backends-ls)

- **Usage:**`mise backends ls`
- **Aliases:**`list`
- **Effect:** read-only
- **Source code:** [`src/cli/backends/ls.rs`](https://github.com/jdx/mise/blob/main/src/cli/backends/ls.rs)

List built-in backends

## Flags [​](https://mise.jdx.dev/cli/backends/ls.html\#flags)

- **`-h --help`** — Print help

## Examples [​](https://mise.jdx.dev/cli/backends/ls.html\#examples)

Installed plugin availability and built-in backends are separate lists

```
mise backends ls
mise plugins ls
```
