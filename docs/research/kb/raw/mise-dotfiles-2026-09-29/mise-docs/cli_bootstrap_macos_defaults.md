# `mise bootstrap macos defaults` [​](https://mise.jdx.dev/cli/bootstrap/macos/defaults.html\#mise-bootstrap-macos-defaults)

- **Usage:**`mise bootstrap macos defaults <SUBCOMMAND>`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Manage macOS defaults from `[bootstrap.macos.defaults]`

Declares typed preferences written with macOS defaults. Application preferences may require restarting the affected application before the change becomes visible.
