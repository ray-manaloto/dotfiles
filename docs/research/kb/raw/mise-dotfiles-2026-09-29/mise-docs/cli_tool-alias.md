# `mise tool-alias` [​](https://mise.jdx.dev/cli/tool-alias.html\#mise-tool-alias)

- **Usage:**`mise tool-alias [-p --tool <TOOL>] [--no-header] [SUBCOMMAND]`
- **Aliases:**`alias`, `aliases`
- **Effect:** read-only
- **Source code:** [`src/cli/tool_alias/mod.rs`](https://github.com/jdx/mise/blob/main/src/cli/tool_alias/mod.rs)

Manage tool version aliases

## Flags [​](https://mise.jdx.dev/cli/tool-alias.html\#flags)

- **`-p --tool <TOOL>`** — Filter aliases by tool
- **`--no-header`** — Don't show table header
- **`-h --help`** — Print help
