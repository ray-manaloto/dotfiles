# `mise bootstrap repos apply` [​](https://mise.jdx.dev/cli/bootstrap/repos/apply.html\#mise-bootstrap-repos-apply)

- **Usage:**`mise bootstrap repos apply [FLAGS]`
- **Effect:** modifies state
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Clone and converge git repos from `[bootstrap.repos]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/repos/apply.html\#flags)

- **`-n --dry-run`** — Print the commands that would run without running them
- **`-y --yes`** — Skip the confirmation prompt
- **`--skip-dirty`** — Skip repos with local changes instead of failing
- **`-h --help`** — Print help
