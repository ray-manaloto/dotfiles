# `mise bootstrap plugins apply` [​](https://mise.jdx.dev/cli/bootstrap/plugins/apply.html\#mise-bootstrap-plugins-apply)

- **Usage:**`mise bootstrap plugins apply [-n --dry-run]`
- **Effect:** modifies state
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Install package manager plugins declared in `[bootstrap.plugins]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/plugins/apply.html\#flags)

- **`-n --dry-run`** — Print what would happen without installing plugins
- **`-h --help`** — Print help
