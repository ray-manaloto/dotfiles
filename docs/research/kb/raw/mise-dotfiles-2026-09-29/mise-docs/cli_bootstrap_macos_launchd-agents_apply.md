# `mise bootstrap macos launchd-agents apply` [​](https://mise.jdx.dev/cli/bootstrap/macos/launchd-agents/apply.html\#mise-bootstrap-macos-launchd-agents-apply)

- **Usage:**`mise bootstrap macos launchd-agents apply [-n --dry-run] [-y --yes]`
- **Effect:** modifies state
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Install and load LaunchAgents from `[bootstrap.macos.launchd.agents]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/macos/launchd-agents/apply.html\#flags)

- **`-n --dry-run`** — Print the commands that would run without running them
- **`-y --yes`** — Skip the confirmation prompt
- **`-h --help`** — Print help
