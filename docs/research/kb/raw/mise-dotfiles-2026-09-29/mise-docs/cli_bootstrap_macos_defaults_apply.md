# `mise bootstrap macos defaults apply` [​](https://mise.jdx.dev/cli/bootstrap/macos/defaults/apply.html\#mise-bootstrap-macos-defaults-apply)

- **Usage:**`mise bootstrap macos defaults apply [-n --dry-run] [-y --yes]`
- **Effect:** modifies state
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Write macOS defaults from `[bootstrap.macos.defaults]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/macos/defaults/apply.html\#flags)

- **`-n --dry-run`** — Print the commands that would run without running them
- **`-y --yes`** — Skip the confirmation prompt
- **`-h --help`** — Print help
