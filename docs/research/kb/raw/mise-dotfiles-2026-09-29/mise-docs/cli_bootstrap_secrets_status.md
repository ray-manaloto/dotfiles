# `mise bootstrap secrets status` [​](https://mise.jdx.dev/cli/bootstrap/secrets/status.html\#mise-bootstrap-secrets-status)

- **Usage:**`mise bootstrap secrets status [-J --json] [--missing]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show whether declared bootstrap secret inputs are available

## Flags [​](https://mise.jdx.dev/cli/bootstrap/secrets/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 if a declared secret input is unavailable
- **`-h --help`** — Print help
