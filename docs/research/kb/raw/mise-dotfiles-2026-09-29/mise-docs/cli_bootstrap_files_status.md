# `mise bootstrap files status` [​](https://mise.jdx.dev/cli/bootstrap/files/status.html\#mise-bootstrap-files-status)

- **Usage:**`mise bootstrap files status [FLAGS]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show configured privileged file and directory state

## Flags [​](https://mise.jdx.dev/cli/bootstrap/files/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 when any resource is not converged
- **`--prompt-secrets`** — Prompt securely for missing bootstrap secret inputs
- **`-h --help`** — Print help
