# `mise bootstrap repos status` [​](https://mise.jdx.dev/cli/bootstrap/repos/status.html\#mise-bootstrap-repos-status)

- **Usage:**`mise bootstrap repos status [-J --json] [--missing]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show the state of git repos from `[bootstrap.repos]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/repos/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 if any configured repo is not in its desired state
- **`-h --help`** — Print help
