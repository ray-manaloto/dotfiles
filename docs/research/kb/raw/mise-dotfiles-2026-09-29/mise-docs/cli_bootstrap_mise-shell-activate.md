# `mise bootstrap mise-shell-activate` [​](https://mise.jdx.dev/cli/bootstrap/mise-shell-activate.html\#mise-bootstrap-mise-shell-activate)

- **Usage:**`mise bootstrap mise-shell-activate <SUBCOMMAND>`
- **Aliases:**`shell`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Manage mise shell activation from `[bootstrap.mise_shell_activate]`

Writes managed activation blocks into the declared shell startup files. The current shell is not reactivated by this command; open a new shell afterward.
