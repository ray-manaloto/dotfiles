# `mise cache clear` [​](https://mise.jdx.dev/cli/cache/clear.html\#mise-cache-clear)

- **Usage:**`mise cache clear [--task <TASK>] [TOOL]…`
- **Aliases:**`c`, `clean`
- **Effect:** modifies state
- **Source code:** [`src/cli/cache/clear.rs`](https://github.com/jdx/mise/blob/main/src/cli/cache/clear.rs)

Delete all cache files

## Arguments [​](https://mise.jdx.dev/cli/cache/clear.html\#arguments)

- **`[TOOL]…`** — Tool(s) to clear cache for e.g.: node, python

## Flags [​](https://mise.jdx.dev/cli/cache/clear.html\#flags)

- **`--task <TASK>`** — Clear output cache entries for a task name or pattern
- **`-h --help`** — Print help
