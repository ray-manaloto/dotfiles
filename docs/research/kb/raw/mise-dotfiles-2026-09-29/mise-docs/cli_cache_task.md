# `mise cache task` [​](https://mise.jdx.dev/cli/cache/task.html\#mise-cache-task)

- **Usage:**`mise cache task [-J --json] <TASK>`
- **Effect:** read-only
- **Source code:** [`src/cli/cache/task.rs`](https://github.com/jdx/mise/blob/main/src/cli/cache/task.rs)

Inspect output cache entries for a task

## Arguments [​](https://mise.jdx.dev/cli/cache/task.html\#arguments)

- **`<TASK>`** — Task name or pattern to inspect

## Flags [​](https://mise.jdx.dev/cli/cache/task.html\#flags)

- **`-J --json`** — Output in JSON format
- **`-h --help`** — Print help
