# `mise bootstrap macos launchd-agents status` [​](https://mise.jdx.dev/cli/bootstrap/macos/launchd-agents/status.html\#mise-bootstrap-macos-launchd-agents-status)

- **Usage:**`mise bootstrap macos launchd-agents status [-J --json] [--missing]`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Show the state of LaunchAgents from `[bootstrap.macos.launchd.agents]`

## Flags [​](https://mise.jdx.dev/cli/bootstrap/macos/launchd-agents/status.html\#flags)

- **`-J --json`** — Output in JSON format
- **`--missing`** — Exit with code 1 if any configured LaunchAgent is not in its desired state
- **`-h --help`** — Print help
