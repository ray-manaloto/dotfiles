# `mise bootstrap files` [​](https://mise.jdx.dev/cli/bootstrap/files.html\#mise-bootstrap-files)

- **Usage:**`mise bootstrap files <SUBCOMMAND>`
- **Effect:** read-only
- **Source code:** [`src/cli/bootstrap.rs`](https://github.com/jdx/mise/blob/main/src/cli/bootstrap.rs)

Manage privileged files and directories from `[bootstrap.files]` and `[bootstrap.directories]`

Use these resources for ownership, permissions, and desired presence on a host. For personal symlinks, copies, or edits, use `[dotfiles]` and `bootstrap dotfiles`.
