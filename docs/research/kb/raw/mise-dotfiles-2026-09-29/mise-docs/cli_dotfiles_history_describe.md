# `mise dotfiles history describe` [​](https://mise.jdx.dev/cli/dotfiles/history/describe.html\#mise-dotfiles-history-describe)

- **Usage:**`mise dotfiles history describe <REF> <TEXT>`
- **Effect:** modifies state
- **Source code:** [`src/cli/dotfiles/history/describe.rs`](https://github.com/jdx/mise/blob/main/src/cli/dotfiles/history/describe.rs)

Set the description of a checkpoint

## Arguments [​](https://mise.jdx.dev/cli/dotfiles/history/describe.html\#arguments)

- **`<REF>`** — Numeric checkpoint ID, `latest`, `latest~N`, or `commit:<sha>`
- **`<TEXT>`** — The new description

## Flags [​](https://mise.jdx.dev/cli/dotfiles/history/describe.html\#flags)

- **`-h --help`** — Print help
