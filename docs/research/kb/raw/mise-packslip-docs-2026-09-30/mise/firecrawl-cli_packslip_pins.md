# `mise packslip pins` [​](https://mise.jdx.dev/cli/packslip/pins.html\#mise-packslip-pins)

- **Usage:**`mise packslip pins [-J --json]`
- **Aliases:**`list`
- **Effect:** read-only
- **Source code:** [`src/cli/packslip/pins.rs`](https://github.com/jdx/mise/blob/main/src/cli/packslip/pins.rs)

List the signers mise has accepted packslips from

## Flags [​](https://mise.jdx.dev/cli/packslip/pins.html\#flags)

- **`-J --json`** — Output in JSON format
- **`-h --help`** — Print help
